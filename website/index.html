How it works

Three moves.
Zero menus.

  1. 01

    Drag any file

    From File Explorer, the desktop, a download bar or an email. Just like you already do.

  2. 02

    Tap Shift

    A wheel opens under your cursor. Tap Shift again to flip from formats to tools.

  3. 03

    Drop on a choice

    JPG, PDF, MP3, Compress. The result is saved beside the original, which is never touched.

FAQ

Questions,
answered.

Something else? Open an issue on GitHub.

Is Shortnut really free?

Yes. Shortnut is free and open source under the MIT License. There are no accounts, limits or ads.

Does it work on Mac or Linux?

Not yet. Shortnut is built for Windows 10 and 11 (64-bit) right now.

Where do converted files go?

Right next to the original, with the same name and the new extension. If a file with that name already exists, Shortnut adds “(2)”, so nothing is ever overwritten. You can pick a fixed output folder in Settings.

I pressed Shift but nothing happened.

Make sure you are actively dragging (the mouse button is held and the file is moving), and that Shortnut is running in the system tray. You can change the key to Ctrl or Alt in Settings. Files can also be opened from the right-click menu → “Convert with Shortnut”.

Windows shows a SmartScreen warning when I install.

Community builds aren't code-signed yet, so Windows may say the publisher is unknown. Click “More info” → “Run anyway”. You can also build the installer yourself from source.

Does dragging with Shift move my file?

No. Shortnut always accepts drops as a copy, so the original stays exactly where it was.

How do I uninstall it?

Settings → Apps → Installed apps → Shortnut → Uninstall. The right-click menu entries are removed too.

Install Shortnut in under a minute

  1. Open the installer. Run Shortnut-Setup.exe from your browser's downloads bar or your Downloads folder.
  2. If Windows shows “Windows protected your PC”, click More info → Run anyway. The installer isn't code-signed yet, so Windows doesn't recognise the publisher.
  3. Click through the installer. No admin rights needed. Shortnut opens when it's done and keeps running in the system tray.
  4. Try it: drag any file, tap Shift while it's moving, and drop it on a format.
